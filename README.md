# sheet_music_app
Extension of college project aiming to improve upon a previously-made sheet music display tablet app.

Previously a group project, I plan to add features to the project and improve on the features already implemented

Current features:
  1. Display sheet music
  2. One-tap navigation through pages
  3. peer-to-peer payload transfer of music, metadata, and messages
  4. offline transfer (uses Google's Nearby Connections API)
  5. elementary file system (uses Android Room database)

Planned features:
  1. Improved interface for connections
  2. Creating sessions ("bands")
  3. View for all bands
  4. Music preview display
  5. Director and musician roles
  6. Instrument and part input (and possibly auto sort-and-send for music from director)
  7. Instrument and part override (director)
  8. Director can choose next song and that song should appear on everyone's device
  9. UI overhaul
